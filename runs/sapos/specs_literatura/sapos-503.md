## Resumo
Registro de projetos coordenados pelos docentes.

## Descrição
Permitir que cada docente registre os projetos que coordena. Para cada projeto, devem ser registradas as seguintes informações:

- Título
- Ano
- Tipo de financiamento (público ou privado)
- Financiador (por exemplo, CNPq, FAPERJ, nome da empresa etc.)
- Valor total

## Versão do produto
Não informado na issue original.

## Justificativa
Os projetos registrados pelos docentes serviriam de insumo para a autoavaliação.

## Caso de uso ou cenário
Um docente registra cada projeto que coordena, informando título, ano, tipo de financiamento, financiador e valor total. Esses dados ficam disponíveis como insumo para o processo de autoavaliação.

## Possível solução
A issue propõe uma funcionalidade de registro de projetos por docente, com os campos: título, ano, tipo de financiamento (público ou privado), financiador e valor total. Não há outros detalhes de implementação na issue original.
